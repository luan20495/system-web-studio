## H-C3 — Management API (NOT IMPLEMENTED)

Current state (verified): `backend/.../data/api/DataApi.kt` holds a route table (`DataRoutes`) and `DataApiHandler`; **no `@RestController` mounts it**. `runtime-api.md` section 0 / 7 keeps tenant-admin data-source management out of the frozen surface. The only live data HTTP surface is C0's `app-runtime` query route.

C3 owns the production routes for:

| Area | Needed |
|---|---|
| Data source | create, read, list, update, delete |
| Credential metadata | set / rotate / remove through a server-side secret field; read returns **metadata only** (never a secret, never a ciphertext) |
| Connection test | per data source, server-side, through the connector SSRF guard |
| Schema / catalog | discovery and read of the discovered schema |
| Query definition | create / update / delete a query of an application |
| Mutation definition | create / update / delete a mutation (idempotency rules of `data-runtime.md` section 4b) |
| TEST / LIVE binding | bind an application's LOCAL ids (`dataSource.sourceId`, query, mapping) to a data source for TEST and for LIVE |

Rules for every route:

- `tenantId` is server-derived (`AccessService.forProject` / workspace); the client never sends it. Unknown body fields are rejected 400. Workspace and project are resolved server-side and a foreign one answers 404 (no existence disclosure).
- A C1 permission is required on every route (reuse existing codes; a new code needs C1). Default deny.
- Audit is required for every write (append-only audit, no secrets in the payload).
- Credentials are never returned and never logged.
- **No browser-callable `/api/v1/data/mutate`.** Writes from a browser go only through the action runtime (`app-runtime/actions/...`), which owns permissions, idempotency derivation and audit.
- Names and shapes: **C3 proposes, C0 reviews, then C0 freezes them in `docs/contracts/v2/` with a DECISIONS entry.** Do not mount anything before that freeze. C0 owns the Spring wiring and the routing integration; C5 only consumes the frozen contract.
- Persistence: V28 already has the tables. A new column or table needs a migration request in `BOARD.md` (C0 numbers it; V30 is C2's, V31 is not allocated).
- Tests: Testcontainers, tenant isolation (second tenant gets 404), permission denial, no-secret-in-response.
