# C5 — Platform (:3001) and Admin (:3002) portals: audit, what was completed, what is blocked (2026-10-07)

Baseline: `integration/v2 @ 1a9995c` backend (stack `c5e2e-pf`, API 42080) + `agent/c5-web` portals built with `API_PROXY_TARGET=http://127.0.0.1:42080`. Runtime audit = every navigation entry of both portals opened as `local.admin` with a real browser:
all pages loaded, **no failing `/api` call, no page error** (the sections that said "Chưa sẵn sàng" were `tenants` on Platform and `groups, sharing, data-sources, byok` on Admin).

## What changed
| Portal | Screen | Route | API (all real) |
|---|---|---|---|
| Platform | Công ty (tenant): list, create, tạm khóa / mở khóa / xóa / khôi phục, members (add, re-role, remove) | `/platform/tenants`, `/platform/tenants/{id}` | `GET/POST /admin/tenants`, `GET /admin/tenants/{id}`, `PATCH …/status`, `GET/PUT/DELETE …/members` |
| Platform | Người dùng & Workspace (+ SYSTEM_ADMIN grant / revoke) moved INTO the Platform nav (it was Admin-only); workspace page now manages members | `/platform/users`, `/platform/workspaces/{id}` | `/admin/users/**`, `/admin/users/{id}/system-admin`, `/workspaces/{w}/members/**` |
| Admin | **Tenant admin** (not a system admin): scoped home, **Công ty của tôi** (tenant + members), system-only URLs refused in words | `/admin`, `/admin/company` | tenant API, authorised per tenant (`TENANT_MEMBERS`) |
| Admin | **Nguồn dữ liệu** for a workspace admin (the C3 panel of THEIR workspace) | `/admin/data-sources` | C3 Management API |
| Both | the console opens for a tenant admin and for someone the server lists `DATA_SOURCE_MANAGE` for (capability `admin.console`); system-only sections are hidden and refused for them | – | `/auth/me` only |
Removed "Chưa sẵn sàng": Công ty (Platform), Nguồn dữ liệu (Admin). Kept, with the exact reason: Nhóm, Chia sẻ, AI riêng của công ty.
Nothing in the C1 contract changed: scope comes from `/auth/me` (`platformScope`, `permissions`, `tenants[].role`, `workspaces[].permissions`); no role name is used for workspace administration.
