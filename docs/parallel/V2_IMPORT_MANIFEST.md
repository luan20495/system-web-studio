## 1. Rules for every import
1. Start from a clean `integration/v2`; `git diff c59604b integration/v2 -- <path>` must be **empty for every file the import overwrites** (otherwise C0 has patched it: merge by hand). Files C0 already patched: `admin/AdminController.kt`, `identity/SecurityConfiguration.kt`, `runtime/Gateway.kt`, `application.yml`, `.env.example`, `docs/contracts/v2/*`, `docs/parallel/{BOARD,MIGRATION_LEDGER,…}.md`.
2. Import only the paths listed under "Import". `git checkout <source> -- <path> …` (it copies files; it does not delete files the source deleted — none of the four sources deletes anything). After it: `git diff --cached --name-only` must contain **nothing outside the list** (the check command is given per agent).
3. Shared files (`docs/parallel/{BOARD,BLOCKERS,DECISIONS}.md`) are **never** taken from a branch: C0 merges them by hand (union, append-only), renumbering collisions (`D-008`/`D-009` exist twice → `D-C2-00a`, `D-C3-00a`, …).
4. One commit per agent: `feat(c<N>): import <what> from <branch>@<sha> (paths only)`, then the step's tests (checklist), then fixes as separate commits. Nothing is called PASS before the Mac run is recorded in `BASELINE.md`.
5. The Flyway files in the import are only those in the ledger (`MIGRATION_LEDGER.md`); an unnumbered migration in a source is ignored.
6. After each import: `grep -rn "TODO(\"W-" backend/src/main` must be empty (wiring skeleton TODOs live only in `backend/src/wiring-skeleton`).
