# System Web Studio

AI-first web builder prototype.

## Demo
- Left: AI prompt/chat
- Right: live product preview
- One-page workspace
- Settings drawer for Git, domain, deploy, access
- History drawer
- Public/private publish flow
- Desktop/tablet/mobile preview
- AI edit mode for sections

## Architecture direction
Hybrid Schema-Driven + Source Code:
1. Reuse components first
2. Generate custom code only when needed
3. Preview from schema
4. Commit versions to Git
5. Security gate before publish
6. Deploy static or dynamic workloads

## Run
Open `index.html` directly in a browser.
